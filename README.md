# SafeVoid · ВКД - Орбитальный Риск

Исследовательский прототип для КосмоХакатона: аналитик задаёт окно внекорабельной деятельности, сервис сравнивает обстановку на траектории МКС.

Это не допуск к реальному выходу.

## Публичный стенд

https://andromedasmart.github.io/vkd-iss-advisor/

Онлайн-режим ходит в API http://46.29.164.87:8000/ v0.2.0 (`POST /api/assess-window`, `GET /api/data-sources-status`). Пустые сутки API заполняются локальным архивом NCEI/DONKI.

Локально: http://127.0.0.1:8001

## Платформа

Слева плашки разделов, справа окно выбранного раздела. Название платформы — **SafeVoid**, заголовок — **ВКД - Орбитальный Риск**.

| Раздел | Что внутри |
|---|---|
| Запрос | Режим, начало ВКД с часовым поясом, длительность, интервал в сутках, сдвиг, отсечение replay |
| Сценарии | Демо, периоды без дыр, список своих расчётов и выгрузка JSON/CSV/ZIP |
| Сравнение | Таблица окон, решение, график опасностей за интервал из Запроса |
| Доказательства | Почему выставлен уровень, обычным языком |
| Источники | Каталог данных, статус и ссылки |
| Журнал предупреждений | Все всплывающие предупреждения и выгрузка архива |

## Что умеет прототип

- Два механизма: радиация (солнечные частицы) и обломки. Геомагнетизм показывается отдельно и не складывается с радиацией.
- Текущий режим: GOES ≥10 МэВ, NOAA Scales, Kp, 3-day forecast, TLE МКС (SGP4), SOCRATES.
- Исторический replay (1 апреля — 31 июля 2024 UTC): берутся только выпуски SWPC с `Issued` не позже отсечения и орбита из GP_HISTORY с `CREATION_DATE` не позже отсечения. Текущие TLE и SOCRATES в прошлое не подставляются.
- День без файлов — дыра, не «всё спокойно».
- Сравнение окон одинаковой длительности. При дыре в критичных данных рекомендация не выдаётся.
- График в Сравнении: ось X — интервал из Запроса (UTC), золотая заливка — выбранный выход, три линии — радиация, обломки, геомагнетизм.
- Полнота — доля известных данных, не оценка безопасности. Под каждым значением есть пояснение, что такое дыра.
- Доказательства и всплывающие предупреждения написаны обычным языком, без служебных идентификаторов.
- Предупреждение появляется после расчёта или смены начала ВКД, если выход выглядит опасным или в данных дыра. Запись попадает в журнал.
- Выгрузка сравнения, сценариев и журнала в JSON, CSV и ZIP.

## Запуск

Нужен Python 3.8+.

```bash
cd ~/Projects/vkd-iss-advisor
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8001
```

Офлайн-replay по архиву: `VKD_LOCAL_ARCHIVES=1`.

Онлайн-API по умолчанию: `VKD_PLANNER_API=http://46.29.164.87:8000`.

JSON расчёта: `GET /api/evaluate?mode=historical&start_utc=2024-05-10%2008:00&duration_hours=6&interval_days=4&offline=on`

Статический стенд: `python scripts/build_stand.py`.

## Тесты

source .venv/bin/activate

## Источники

| Величина | Источник | Роль |
|---|---|---|
| Протоны ≥10 МэВ | NOAA SWPC GOES JSON | наблюдение |
| 3-day forecast S/G/R, Kp | SWPC / архив NCEI | внешний прогноз |
| Kp | SWPC planetary K-index | наблюдение |
| TLE ISS 25544 | CelesTrak GP | орбита, текущий режим |
| GP ISS 25544 | Space-Track GP_HISTORY | историческая орбита |
| Сближения | CelesTrak SOCRATES Plus | внешний прогноз, только current |

Локальные копии лежат в `data/archives/`. Если задан `VKD_DATA_DIR`, сравнение читает его в первую очередь.
